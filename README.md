Thirumana Sangamam – Wedding Event Website

A modern and responsive wedding event website designed to provide an elegant digital experience for couples, families, and guests. The website focuses on presenting wedding-related information, event details, services, and contact information through a clean and attractive interface.

## 🌐 Live demo link 
https://www.figma.com/design/dlJpE2rKnyXY6zkCmKffai/Untitled?node-id=0-1&t=HFSrozyJAINQtDlb-1

## 🎨 Design

The website UI/UX was designed using Figma with a focus on:

- Clean and modern layout
- Elegant wedding-themed visual design
- Responsive user interface
- Easy navigation
- Clear content presentation
- User-friendly sections and call-to-action buttons

## 🚀 Features

- 🏠 Attractive Home Page
- 💍 Wedding/Event Information
- 📋 Services Section
- 🖼️ Visual Gallery
- 👥 About Section
- 📞 Contact Section
- 📱 Responsive Design
- ✨ Modern UI with smooth visual presentation
- 🔗 Easy navigation between sections
